NexaShop — Consultas SQL

Atividade de consolidação de **Consultas SQL com MySQL**, realizada para a disciplina de Análise e Desenvolvimento de Sistemas (ADS).

O projeto utiliza o banco de dados fictício **NexaShop**, um e-commerce de eletrônicos e variedades. Foram desenvolvidas consultas SQL para análise e obtenção de indicadores de negócio.
